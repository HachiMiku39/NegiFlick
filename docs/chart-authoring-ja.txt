NegiFlick 自作譜面 制作ガイド v1

NegiFlick は、歌詞に合わせて文字を入力するリズムゲームです。自作譜面では、入力する文字と、その文字を打つタイミングを決めます。動画・歌詞・譜面は、ご自身が制作・利用・配布できるものを使用してください。

1. まず用意するもの
・長さ 600 秒以内の MP4 動画。iOS で再生しやすい H.264 + AAC を推奨します。
・曲名、作者、固有の曲 ID、BPM（整数 40〜400）。
・任意の PNG カバー。
・任意のタイムコード付き歌詞（LRC、拡張 LRC、SRT、lyrics JSON）。
ブラウザで選択した動画はサーバーへ送信されません。編集データはこのブラウザの localStorage に自動保存されます。共有端末ではプロジェクトを保存し、使用後にサイトデータを消してください。動画本体は自動保存されないため、再度開くときに選択し直します。

2. 日本語の入力単位
1 ノーツにつき、ひらがなまたはカタカナ 1 文字です。歌詞表示には漢字を使えますが、入力対象は読みをかなに直してください。例：「恋」→「こ」「い」。カタカナはひらがなと同じキー・方向で入力します。濁音・半濁音・小書きかな・長音も使えます。「きゃ」は「き」「ゃ」の 2 ノーツです。「が」「ぱ」は、それぞれ 1 ノーツです。
対応文字：あいうえお／かきくけこ／さしすせそ／たちつてと／なにぬねの／はひふへほ／まみむめも／やゆよ／らりるれろ／わをん／ー〜、および対応する濁音・半濁音・ゔ・ぁぃぅぇぉゃゅょっゎ。
句読点や空白は入力ノーツにしません。漢字の読みは作者が確認してください。現在のブラウザ版は読みを自動生成しません。

入力の方向は文字から決まります。各行の「あ・か・さ…」は TAP、続く「い・き・し…」は左、「う・く・す…」は上、「え・け・せ…」は右、「お・こ・そ…」は下です。例外を含め、エディタが実際のキーと方向を表示します。文字の方向だけを任意に変える機能はありません。

3. 五つの難度と「点灯」
順序は EASY / NORMAL / HARD / EXTREME / BTL です。難度名は英語のままです。
各ノーツに五つのスイッチがあります。ON の難度でその文字を入力し、OFF の難度ではその文字は入力対象になりません。同じ文字を複数の難度で使っても時刻と方向は共通です。文字自体によって難度が自動的に決まるわけではありません。
基本方針として EASY は間隔を広くして短い語の主要な音から、NORMAL は歌の主要部分を追加、HARD はより細かい音、EXTREME / BTL は密度と長い連続入力を慎重に調整します。これは制作の目安です。BTL だから全ての文字を必ず点灯させる、といった自動規則はありません。
レベルは難度ごとに 1〜99 を指定します。難度を提供しないときはレベルを空欄にし、その難度の全ノーツを OFF にしてください。五難度は初めから編集できますが、実際に提供する各難度には少なくとも 1 ノーツ必要です。
同一難度の同一 30 Hz tick に 2 ノーツは置けません。異なる難度だけで有効な 2 ノーツなら同じ tick に配置できます。

4. 時刻と歌詞の合わせ方
ノーツの時刻は、動画の再生位置における「命中時刻」です。画面に出現する時刻ではありません。判定は従来の 30 Hz のままです。エディタのプレビューは作譜の目安であり、ゲームの判定そのものではありません。
先読みは標準 1700 ms、設定可能範囲 1000〜5000 ms。最初のノーツには十分な準備時間が必要です。先頭で歌い始める動画は、動画側に余白を追加してください。歌詞だけずらしても動画は変わりません。最後のノーツは動画終了の 0.5 秒以上前に置いてください。
LRC / SRT の行タイムコードは歌詞表示の開始時刻です。行だけのタイムコードから全ての音節の正しい時刻は分かりません。「この行を仮配置」は行内を等分する下書きです。動画を再生し、文字を横にドラッグして調整するか、文字列をキューに入れて Enter で順に配置してください。拡張 LRC の <mm:ss.xx> は文字/語のタイムコードとして利用します。
Crimax は各ノーツに付けられる既存エフェクトのフラグです。この authoring v1 は通常文字ノーツを作る形式で、間奏ノーツや途中 BPM 変更の作成 UI はまだ提供しません。

5. 書き出しとゲームへの読み込み
「チェック」で入力文字、先読み、動画範囲、難度、同時 tick を確認します。「曲包 ZIP を書き出す」で、次のファイルをローカルでまとめます。
  negiflick-pack.json  曲情報と五難度レベル
  authoring.json       命中時刻・文字・難度・歌詞
  media.mp4            選択した動画（再圧縮しません）
  cover.png            任意のカバー
NegiFlick の RESOURCE PACK INPUT で ZIP を選択すると、既存の Swift コンパイラが authoring.json をゲーム用の譜面に変換します。JSON 文を手で書く必要はありません。プロジェクト JSON は編集再開用で、曲包 ZIP とは別です。
配布前に NegiFlick 内で再生・入力・歌詞同期を確認してください。ブラウザで再生できても、すべての動画コーデックが iOS で再生できるとは限りません。

6. 中国語と英語
ja / zh / en は曲ごとに明示します。アプリの表示言語や歌詞の訳文は入力キーボードを決めません。
中国語：漢字 1 文字につき 1 ノーツ、拼音の頭文字を入力します。ブラウザ版では頭文字 A〜Z を作者が指定してください。例：「你」「好」→ N・H。多音字は歌詞の文脈に合わせます。
英語：単語 1 個につき 1 ノーツ、単語の頭文字を入力します。例：Hello world → H・W。don't は 1 単語で D。任意の別の文字に差し替えることはできません。

技術仕様と入力の正確な規則は、リポジトリの CHART-FORMAT.txt / CustomChart.swift / InputLanguage.swift を参照してください。
